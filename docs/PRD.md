# VeriLearn Product Requirements

The product requirements define VeriLearn as an evidence-first learning assistant for technical lectures. The planned frontend experience includes a workspace, lecture upload flow, timestamped transcript, evidence-backed concepts, verification states, source-grounded quizzes, and accessible responsive navigation.

The current repository milestone is foundation setup only. Website features, backend services, persistence, transcription, retrieval, LLM generation, authentication, and production deployment are out of scope.
