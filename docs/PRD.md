# VeriLearn Product Requirements

The product requirements define VeriLearn as an evidence-first learning assistant for technical lectures. The planned frontend experience includes a workspace, lecture upload flow, timestamped transcript, evidence-backed concepts, verification states, source-grounded quizzes, and accessible responsive navigation.

The current repository milestone is the frontend vertical slice. Website routes, responsive layouts, evidence inspection interactions, local mock data, and demo processing states are implemented. Backend services, persistence, transcription, retrieval, LLM generation, authentication, and production deployment remain out of scope for this milestone.
